# yilin · 公众号排版铁律

把中文内容排成微信公众号文章页。**这个 skill 只做排版,不改写内容、不加设计私货。** 唯一的设计依据是下面 8 条铁律;除此之外不引入任何额外字体、动效、配色主张。

## 8 条排版铁律(唯一设计约束)

1. **正文:14px**。
2. **小标题:17px 或 20px**(两级标题在这两个值里选)。
3. **行间距:line-height 1.6**(默认,不另调)。
4. **两端缩进:左右各 16px**(正文与块用 `margin-left:16px; margin-right:16px`,即 `margin:0 16px ...`)。
5. **段前距/段后距:不特别改**——只用底部 `margin-bottom` 控制段间隔,不额外设段前。
6. **居中:该居中的地方保留居中**(`text-align:center`),其余默认左对齐。
7. **视觉大标题可以更大**,比如**浅色大字**(如极浅灰 60–80px 的序号/标题),由你根据版式自行处理大小与位置。
8. **中文标点一律全角**,不出现半角标点(，。、：；""（）—— 用全角;英文术语/标识符如 comp-voice、judge.json 保留原样)。

## 交付机制:让规则在公众号编辑器里活下来(必须做)

公众号编辑器粘贴时会**删掉 `<style>` 标签和所有 class 选择器**,只保留写在标签上的内联样式;外链图片会被防盗链拦掉。所以为了让上面 8 条真的不变形:

- **全部样式内联**写在每个元素的 `style="..."` 上。
- **禁止** `<style>` 块、**禁止** class 选择器。
- **不嵌外链图片**(图片让用户在编辑器里上传素材库);需要图位时留一个带说明的占位块。
- 居中靠**父元素** `text-align:center`,不靠 `margin:auto`。
- 外层容器 `max-width:677px; margin:0 auto`(公众号正文宽度)。
- 字体栈用 `-apple-system,BlinkMacSystemFont,"PingFang SC","Helvetica Neue",Arial,sans-serif`(公众号最终会套自己的字体,但写上无害)。

## 步骤

1. 取内容:参数是 markdown 路径就 Read;是直接粘的正文就用原文。**逐字保留,不改写、不润色、不增删。**
2. 标点规范化:把正文里的半角中文标点改全角(`,`→`，` `.`→`。` `:`→`：` `;`→`；`),英文直引号→全角 `""`;但**不动**英文术语、文件名、代码标识符里的半角符号。
3. 按 8 条铁律生成**全内联** HTML:正文段 `<p style="font-size:14px;line-height:1.6;margin:0 16px 16px;color:rgb(51,51,51);">`;小标题 `font-size:20px`(或 17)`;font-weight:700;margin:0 16px 22px;`;需要时加浅色大字视觉标题;该居中处 `text-align:center`。
4. 写到 `<来源同目录>/yilin-<标题或时间>.html`(直接粘的内容写到当前目录)。
5. **自检**(Bash):确认 `grep -c '<style'`=0、`grep -c 'class='`=0、无外链图;再扫一遍正文无残留半角中文标点。任一不过则修。
6. 用 `open <file>` 在浏览器打开,告诉用户:在渲染页面上 Ctrl+A → Ctrl+C → 公众号编辑器 Ctrl+V。

## 硬规则

- **只排版,不创作**:不改用户的字句。
- **8 条铁律是全部设计依据**,不加额外审美主张。
- **粘贴安全优先于好看**:任何会被公众号编辑器删掉的写法(`<style>`/class/外链图)一律不用。
- 自检不通过不交付。

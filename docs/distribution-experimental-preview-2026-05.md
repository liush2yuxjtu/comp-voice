## English

I shipped an experimental preview of company-voice: a local Claude Code plugin that turns meeting audio plus enterprise context into a reviewable WeChat article draft.

The point is not just "AI writes a draft." The point is that every intermediate artifact is preserved: transcript, enterprise context, synthesis, draft, preview HTML, and judge JSON.

Start with the golden-run folder if you want to inspect the product without installing anything.

Demo: https://htmlpreview.github.io/?https://gist.githubusercontent.com/LiuShiyuMath/c8a8c8dda05a8ce6c6d043d20f0737f0/raw/company-voice-experimental-preview-20260527.html

## 中文

我发布了 company-voice 的 experimental preview：一个本地 Claude Code plugin，把会议录音 + 企业上下文变成可审阅的微信公众号草稿。

它不是“再写一篇 AI 公众号”。重点是把 transcript、企业上下文、synthesis、draft、preview HTML、judge JSON 全部保留下来，让内容不是盲信，而是能 review。

如果不想安装，先看 golden-run artifact 就能理解完整 pipeline。
